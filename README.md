# Hadith video — Niyyah

A deterministic HTML/CSS/JavaScript project that renders the supplied Bengali voice-over and timestamped subtitles into MP4 files through Playwright and FFmpeg in GitHub Actions. The audio is 79.68 seconds; the timestamp file ends at 82 seconds, so the renderer pads the audio with silence to 82 seconds rather than stretching or cutting visuals.

## Files and assets

- `index.html`, `style.css`, `art.js`, `layout.js`, `scenes.js`, `lines.js`, `render.js`
- `package.json`, `.gitignore`, `.github/workflows/render.yml`
- Original inputs copied unchanged: `timestamps.txt`, `audio.mp3`, `logo.png`, `google-play-badge.png`

The supplied image files are PNGs, so their real names are preserved and referenced directly; they have not been renamed to JPG. Bengali and Arabic use system fonts installed by the workflow. The scene illustrations are local inline SVG.

## Render on GitHub

1. Create a GitHub repository and upload all project files, preserving `.github/workflows/render.yml` exactly.
2. Open **Actions → Render video (all ratios) and publish Release → Run workflow**. For a first check, set `test_seconds` to `10` and `ratios` to `9x16,16x9`. Test runs create workflow artifacts but do not publish a Release. For the full render, leave `test_seconds` empty.
3. When the full workflow is green, open the repository's **Releases** section and download the ratio and quality you need.

If publishing is blocked, open **Settings → Actions → General → Workflow permissions**, enable **Read and write permissions**, save, and rerun. If one ratio fails, rerun with only that ratio in `ratios` and reuse the same `release_tag` to add its files to the existing Release.

- **9:16** — TikTok, Instagram Reels/Stories, YouTube Shorts, Facebook Reels
- **16:9** — YouTube landscape, websites, presentations
- **1:1 / 4:5 / 3:4** — feed posts
- **4:3** — classic screens and slide decks
- **4K** — archive / high-quality delivery; **FHD** — normal upload; **HD** — smaller files

## Local commands

`npm install && npx playwright install chromium`; install FFmpeg and suitable Bengali/Arabic fonts too. Then `node render.js`, or subset with `node render.js --ratios 9x16,16x9 --tiers fhd,hd`. Test with `node render.js --test 10 --ratios 9x16 --tiers hd`. Export still frames with `node render.js --still 1,20,40 --ratios 9x16`.

## Edit text or timing

Edit `timestamps.txt` while preserving `start | end | text | emotion_tag`, commit, then rerun the workflow. `lines.js` is regenerated by `render.js` from the timestamp source. Choose `ratios` and `tiers` in the workflow inputs to render only selected outputs. Use a new `release_tag` for a new Release; reuse the same tag to add/rebuild assets.

## Design notes

The main palette is emerald and gold, with vector mosque, crescent, book, Kaaba, lantern, heart and reflection visuals. All timestamp lines remain separate subtitles with their original Bengali wording and timings. The visual scene is a designed interpretation of the script; verify religious quotations and Arabic orthography before public distribution.
